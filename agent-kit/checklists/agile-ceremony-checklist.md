# Checklist: Agile Ceremonies

## Backlog Refinement

- [ ] Story có value rõ.
- [ ] AC testable.
- [ ] Dependency/risk rõ.
- [ ] Estimate được.
- [ ] Story quá lớn đã tách nhỏ.

## Sprint Planning

- [ ] Sprint goal rõ.
- [ ] Capacity thực tế.
- [ ] Story đạt DoR.
- [ ] Risk/dependency có owner.
- [ ] Support/incident buffer được tính.

## Daily

- [ ] Tập trung vào progress tới sprint goal.
- [ ] Blocker có owner.
- [ ] WIP không vượt năng lực review/test.
- [ ] Risk mới được nêu sớm.

## Sprint Review

- [ ] Demo theo user value.
- [ ] Nêu metric hoặc evidence.
- [ ] Ghi feedback thành backlog item.
- [ ] Nêu phần chưa hoàn tất nếu có.

## Retrospective

- [ ] Dựa trên sự kiện và dữ liệu.
- [ ] Chọn ít action nhưng có tác động.
- [ ] Action có owner và due date.
- [ ] Theo dõi action cũ.
