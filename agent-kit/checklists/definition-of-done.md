# Checklist: Definition of Done

Một story được xem là done khi:

- [ ] Acceptance criteria pass.
- [ ] Code review xong.
- [ ] Unit/integration/UI/API test phù hợp đã chạy.
- [ ] Regression impact đã được QC xác nhận.
- [ ] Không còn blocker/critical defect mở.
- [ ] Security concern đã xử lý hoặc có risk acceptance.
- [ ] Performance risk đã được kiểm tra theo mức ảnh hưởng.
- [ ] Logging/metrics/tracing đủ cho vận hành.
- [ ] Migration/rollback notes đã cập nhật nếu có.
- [ ] Documentation hoặc release notes đã cập nhật nếu cần.
- [ ] Product owner hoặc người được ủy quyền chấp nhận.
