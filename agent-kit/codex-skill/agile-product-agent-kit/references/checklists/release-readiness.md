# Checklist: Release Readiness

## Scope

- [ ] Scope release rõ.
- [ ] Feature flag/config đã sẵn sàng nếu có.
- [ ] Dependency external đã xác nhận.
- [ ] Backward compatibility đã kiểm tra.

## Quality

- [ ] CI xanh.
- [ ] Test summary được QC xác nhận.
- [ ] Blocker/critical defect đã đóng.
- [ ] Regression scope đã chạy.
- [ ] Security finding high/critical đã xử lý hoặc có risk acceptance.

## Operation

- [ ] Deploy owner rõ.
- [ ] On-call/support owner rõ.
- [ ] Dashboard/alert sẵn sàng.
- [ ] Runbook hoặc verification steps rõ.
- [ ] Rollback trigger và rollback steps rõ.
- [ ] Data migration có backup/restore hoặc plan giảm rủi ro.

## Communication

- [ ] Stakeholder được thông báo.
- [ ] Release notes hoặc customer communication sẵn sàng nếu cần.
- [ ] Support FAQ hoặc known issue sẵn sàng nếu cần.
