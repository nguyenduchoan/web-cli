# Workflow: RACI

RACI giúp phân định ai Responsible, Accountable, Consulted, Informed trong từng hoạt động.

| Activity | PM | BA | SA | BE | FE | QC | UX/UI | DevOps/SRE | Security | Data | Scrum Master |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Product brief | A/R | C | I | I | I | I | C | I | I | C | I |
| PRD | A | R | C | C | C | C | C | I | C | C | I |
| User story / AC | C | A/R | C | C | C | C | C | I | C | I | I |
| UX flow | C | C | I | I | C | C | A/R | I | I | C | I |
| Solution design | C | C | A/R | C | C | C | C | C | C | I | I |
| API/data contract | I | C | A | R | C | C | I | I | C | I | I |
| Implementation BE | I | C | C | A/R | C | C | I | I | C | I | I |
| Implementation FE | I | C | C | C | A/R | C | C | I | C | I | I |
| Test plan | I | C | C | C | C | A/R | C | I | C | I | I |
| Security review | I | C | C | C | C | C | I | C | A/R | I | I |
| Release plan | A | I | C | C | C | C | I | R | C | I | I |
| Sprint ceremony | C | C | C | R | R | R | C | I | I | I | A/R |
| Metric readout | A | I | I | I | I | I | C | I | I | R | I |

Legend:

- R: Responsible, người trực tiếp làm.
- A: Accountable, người chịu trách nhiệm cuối.
- C: Consulted, cần tham vấn.
- I: Informed, cần được thông báo.
